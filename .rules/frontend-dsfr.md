# Frontend DSFR

## Must Do
- Use react-dsfr component library: https://components.react-dsfr.codegouv.studio/?path=/docs/%F0%9F%87%AB%F0%9F%87%B7-introduction--page
- Follow French government design system standards
- Import DSFR components: `import { Button, Input } from "@codegouvfr/react-dsfr"`

## Must Not Do
- Create custom components that duplicate DSFR functionality
- Override DSFR styles without justification

## Key Patterns
- Use DSFR components for all UI elements (buttons, inputs, tables, alerts)
- Apply DSFR spacing and typography utilities
- Maintain accessibility compliance (RGAA standards)

## Integration
- DSFR provider wraps application root
- Use DSFR icons and color tokens
- Follow DSFR documentation for component props
